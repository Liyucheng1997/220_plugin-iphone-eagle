# iPhone 照片同步 — Eagle 插件

在 Windows 上通过数据线直接读取 iPhone/iPad 相机胶卷，在 Eagle 里预览、
一键导入、备份到文件夹，或从手机删除。无需 iCloud、无需把照片先拖到电脑。

底层走 Windows 自带的“便携设备（WPD）”通道，也就是资源管理器里
“Apple iPhone → Internal Storage → DCIM”那条路，所以不需要装任何驱动
（除了 Apple 自己的 USB 驱动），也不需要 .NET SDK 或编译环境。

---

## 一、准备工作（只需一次）

1. 电脑装过 **iTunes** 或 **“Apple 设备”**（Microsoft Store 里的 Apple Devices）。
   平时用数据线连过 iPhone 传文件就说明已经装好。
2. 用数据线把 iPhone 连到电脑。
3. **解锁手机**，弹出“要信任此电脑吗”时点 **信任**，输入锁屏密码。
4. 在资源管理器“此电脑”里能看到 **Apple iPhone** 图标，就说明通道正常。

> ⚠️ 如果 iPhone 开了 iCloud「优化 iPhone 存储」，部分照片原图不在手机上，
> 只有缩略图。这类照片无法通过数据线导出（所有同类软件都一样，包括
> iMazing）。要导出全部，可在 iPhone 设置里临时改为「下载并保留原始照片」。

---

## 二、把插件装进 Eagle

1. 打开 Eagle。
2. 菜单 **插件 → 开发者 → 导入本地项目**（或“Plugin → Developer → Import Local Project”）。
3. 选择这个文件夹：
   ```
   F:\我的编程项目\210_Apple照片同步\plugin
   ```
   （注意是里面的 `plugin` 子文件夹，不是最外层。）
4. 导入后在插件列表里会出现 **“iPhone 照片同步”**，点它启动。

---

## ⚡ 照片很多（上万张）？

- 读取列表用的是 **WPD 底层接口**（iMazing 那类工具用的通道），上万张照片
  也能在**几秒内**列完（实测约 8000 张 2 秒）。
- 仍建议**把自动锁定关掉**：iPhone → 设置 → 显示与亮度 → 自动锁定 → **永不**。
  手机锁屏会中断数据线通道；导入大量照片（要传好几 GB）时尤其要保持解锁。

## 三、怎么用

1. 插上并解锁 iPhone，点插件窗口左上角的 **刷新**。
2. 稍等片刻（第一次读取列表，照片多时可能要几十秒），会看到照片网格，
   缩略图随滚动逐步加载。
3. 顶部可以 **按文件名筛选**、切换 **图片/视频**、改 **排序**。
4. **浏览**：网格是虚拟渲染的，上万张也能丝滑滚动。**单击**选择照片（可 Shift 连选、全选），**双击**打开大图查看器。
5. **大图查看器**里：← → 或滑动切换上一张/下一张，Esc 关闭；可选一个 Eagle 分类后**添加到 Eagle**，也可**从手机删除**（释放手机空间）。
6. 导入有三种方式：
   - **导入全部到 Eagle**：不用挑，直接把手机上所有照片/视频搬进 Eagle。
   - **仅导入新增**：只导入「上次以来新拍、还没导过」的照片（插件会按设备
     记住导过哪些，可反复点，每次只补新的）。
   - **导入所选**：先在网格里挑（点选、Shift 连选、或全选），再导入这些。
5. **浏览和管理就在 Eagle 里做**——导入后照片进了 Eagle 资源库（自动打 `iPhone`
   标签），用 Eagle 的瀑布流浏览、打标签、分类，这就是你要的「Eagle 体验」。
   插件本身只负责把照片快速、可靠地从手机搬进来。
6. 另外两个按钮：
   - **备份所选…**：选一个电脑文件夹，把选中的原图复制过去（不进 Eagle）。
   - **删除所选…**：二次确认后，直接从手机相机胶卷删除（不可撤销）。
   - 「导入所选」完成后也会问你「是否顺手从手机删掉这些」。

> 💡 为什么这样设计：手机通过数据线是「相机协议」，实时翻看上万张会很慢；而
> Eagle 快是因为它读的是**本地硬盘 + 预生成缩略图**。所以正确姿势是——用插件把
> 照片一次性搬到本地/Eagle，然后在 Eagle 里享受本地速度的浏览。iPhone 无法像
> U 盘/SD 卡那样被挂成一个盘符文件夹（苹果不开放），这条路走不通。

## 四、遇到问题先跑「诊断」

因为设备千差万别，如果刷新没反应、看不到照片、或缩略图不出来，
**先跑一下诊断脚本**，把输出发我，我据此修：

1. 插上并解锁 iPhone（点过“信任”）。
2. 打开 **PowerShell**，粘贴运行：
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "F:\我的编程项目\210_Apple照片同步\plugin\scripts\iphone.ps1" -Action diagnose
   ```
3. 把它打印的那一整行 JSON 复制给我。

那行 JSON 会告诉我们：有没有检测到设备、找没找到 DCIM、能不能读到照片样本、
缩略图能不能生成（`thumbTest`）。这样能快速定位是设备层、还是界面层的问题。

也可以单独测“列出前 20 张”：
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "F:\我的编程项目\210_Apple照片同步\plugin\scripts\iphone.ps1" -Action list -Max 20
```

## 五、已知限制 / 待办

- iCloud「优化存储」的照片无法导出（见上）。
- 缩略图依赖 Windows 的 HEIC 解码；若系统没装 HEIF 扩展，HEIC 缩略图
  可能出不来（照片仍可选中、导入、备份），届时给格子显示文件名占位。
  可在 Microsoft Store 搜索安装免费的 “HEIF 图像扩展”。
- 删除用的是 Windows Shell 的删除动作；个别系统/语言下动作名不同可能失败，
  失败会明确提示，可重试或手动删。
- 目前只读 DCIM（相机胶卷），不含 iCloud 共享相册等。

```
plugin/
  manifest.json        Eagle 插件清单
  index.html           界面
  logo.png             图标
  css/style.css        样式
  js/app.js            界面逻辑（选择/筛选/导入/备份/删除）
  js/backend.js        Node ↔ PowerShell 桥接
  scripts/iphone.ps1   核心后端：列设备/列照片/缩略图/复制/删除
```

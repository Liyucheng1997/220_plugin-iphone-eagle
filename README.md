# 手机照片同步 — Eagle 插件（iPhone + 安卓）

在 Windows 上通过数据线直接读取手机里的照片/视频，在 Eagle 里预览、
一键导入、备份到文件夹，或从手机删除。**iPhone/iPad 和安卓手机都支持**。
无需 iCloud、无需云盘，也不用先把照片手动拖到电脑。

底层走 Windows 自带的“便携设备（WPD）/ MTP”通道，也就是资源管理器里
“此电脑 → 你的手机 → 内部存储”那条路。iPhone 和安卓都说 MTP 协议，所以
同一套引擎两边通用，不需要 .NET SDK 或编译环境。

---

## 一、准备工作（只需一次）

**iPhone / iPad：**
1. 电脑装过 **iTunes** 或 **“Apple 设备”**（Microsoft Store 里的 Apple Devices）。
   平时用数据线连过 iPhone 传文件就说明已经装好。
2. 用数据线把 iPhone 连到电脑，**解锁手机**。
3. 弹出“要信任此电脑吗”时点 **信任**，输入锁屏密码。
4. 在资源管理器“此电脑”里能看到 **Apple iPhone** 图标，就说明通道正常。

**安卓（Android）：**
1. 一般**不用装驱动**，Windows 自带 MTP 驱动即可。
2. 用数据线把手机连到电脑，**解锁手机**。
3. **下拉通知栏**，找到“为 USB 充电 / USB 用途”那条通知，把它改成
   **“传输文件 / 文件传输 / MTP”**（默认往往是“仅充电”，那样电脑读不到照片）。
4. 在资源管理器“此电脑”里能看到你的手机型号图标，就说明通道正常。

> ⚠️ iPhone 若开了 iCloud「优化 iPhone 存储」，部分照片原图不在手机上，
> 只有缩略图。这类照片无法通过数据线导出（所有同类软件都一样，包括
> iMazing）。要导出全部，可在 iPhone 设置里临时改为「下载并保留原始照片」。

## 二、把插件装进 Eagle

1. 打开 Eagle。
2. 菜单 **插件 → 开发者 → 导入本地项目**（或“Plugin → Developer → Import Local Project”）。
3. 选择这个文件夹：
   ```
   F:\我的编程项目\210_Apple照片同步\plugin
   ```
   （注意是里面的 `plugin` 子文件夹，不是最外层。）
4. 导入后在插件列表里会出现 **“手机照片同步”**，点它启动。
5. 如果同时插了多台设备（或有 U 盘/SSD 也走 MTP），窗口左上角的下拉框可以
   **手动选设备**；插件会优先自动选中像手机的那一个。

## ⚡ 照片很多（上万张）？

- 读取列表用的是 **WPD 底层接口**（iMazing 那类工具用的通道）。插件会先尝试
  **批量属性读取**（一次问一整个文件夹，而不是一张一张问）；个别机型不支持
  批量接口时自动退回逐张读取。

- **插上手机后的第一次读取会很慢，之后就很快** —— 这是 Windows 的 WPD/MTP
  驱动在缓存文件属性，跟插件走哪条代码路径无关（实测：批量和逐张两种路径，
  热了之后都是 1.0 秒，没有差别）。

  | | 每个文件 | iPhone 实测 7906 张 |
  |---|---|---|
  | **冷**（刚插上，第一次读） | ~28ms | **约 4 分钟** |
  | **热**（之后每次读） | ~0.02ms | **1.2 秒** |

  > 📌 以前 README 写的「8000 张 2 秒」是**热缓存**下量出来的，会误导人，
  > 已更正。真实体验是：插上后第一次等几分钟，之后每次刷新都是一两秒。
  > 所以**别频繁拔插数据线**，插着不动最舒服。

- 状态栏的「已找到 N 张」每 200 张跳一次；冷读取时它爬得慢是正常的，不是卡死。
- 仍建议**保持手机不锁屏**：手机锁屏会中断数据线通道；导入大量照片
  （要传好几 GB）时尤其要保持解锁。
  - iPhone：设置 → 显示与亮度 → 自动锁定 → **永不**。
  - 安卓：开发者选项里可开“充电时不锁屏”，或临时把自动锁屏调长。

## 三、怎么用

1. 插上并解锁手机（iPhone 点过“信任”、安卓切到“传输文件/MTP”），点插件窗口
   左上角的 **刷新**。
2. 稍等片刻会看到照片网格，缩略图随滚动逐步加载。照片按月份分组
   （iPhone 从相册文件夹名取月份；安卓从文件名里的日期推断，取不到的归到
   “未知日期”）。
3. 顶部可以 **按文件名筛选**、切换 **图片/视频**、改 **排序**。
4. **浏览**：网格是虚拟渲染的，上万张也能丝滑滚动。**单击**选择照片（可 Shift 连选、全选），**双击**打开大图查看器。
5. **大图查看器**里：← → 或滑动切换上一张/下一张，Esc 关闭；可选一个 Eagle 分类后**添加到 Eagle**，也可**从手机删除**（释放手机空间）。
6. **拖拽到 Eagle（推荐，最顺手）**：在缩略图上**按住左键直接拖**，就能拖进
   Eagle 的任意文件夹。拖的是**原图**，不是缩略图。
   - Eagle 只能接收电脑上真实存在的文件，所以插件必须先把原图从手机拉下来。
     为了让拖拽「一把就中」，插件会在你**鼠标停在照片上**和**刚按下左键**时
     就提前开始拉原图——通常等你真的拖动时它已经在本地，拖拽是瞬时的。
   - 万一还没拉完，会有一个**跟着鼠标的缩略图虚影**（带进度条）告诉你在准备中：
     此时**按住别松手**，文件一到就自动接管成真正的拖拽。松手了也不白等——
     原图已缓存，再拖一次就是瞬时的。
   - 选中多张（右键勾选）后再拖，会一次把整组拖进去，虚影右上角显示数量。
7. 导入有三种方式：
   - **导入全部到 Eagle**：不用挑，直接把手机上所有照片/视频搬进 Eagle。
   - **仅导入新增**：只导入「上次以来新拍、还没导过」的照片（插件会按设备
     记住导过哪些，可反复点，每次只补新的）。
   - **导入所选**：先在网格里挑（点选、Shift 连选、或全选），再导入这些。
8. **浏览和管理就在 Eagle 里做**——导入后照片进了 Eagle 资源库（自动打 `手机照片`
   标签），用 Eagle 的瀑布流浏览、打标签、分类，这就是你要的「Eagle 体验」。
   插件本身只负责把照片快速、可靠地从手机搬进来。
9. 另外两个按钮：
   - **备份所选…**：选一个电脑文件夹，把选中的原图复制过去（不进 Eagle）。
   - **删除所选…**：二次确认后，直接从手机删除（不可撤销）。
   - 「导入所选」完成后也会问你「是否顺手从手机删掉这些」。

> 💡 为什么这样设计：手机通过数据线是「相机/MTP 协议」，实时翻看上万张会很慢；
> 而 Eagle 快是因为它读的是**本地硬盘 + 预生成缩略图**。所以正确姿势是——用插件
> 把照片一次性搬到本地/Eagle，然后在 Eagle 里享受本地速度的浏览。手机无法像
> U 盘/SD 卡那样被稳定挂成一个盘符文件夹，这条路走不通。

## ⚠️ 在别的电脑上装完，一刷新就报 `ParserError / UnexpectedToken`？（1.2.1 已修）

`iphone.ps1` 里有中文，而它当时存成了**不带 BOM 的 UTF-8**。PowerShell 5.1 读不带 BOM 的
`.ps1` 时用的是**系统 ANSI 代码页**——在中文 Windows（代码页 936/GBK）上，UTF-8 的中文
字节被按 GBK 解码，某个字符串的结束引号会被当成双字节的尾字节吃掉，于是整个脚本在运行
前就解析失败，连「检测设备」都跑不了。

阴险的是：开发机如果开了「Beta: 使用 Unicode UTF-8 提供全球语言支持」（代码页 65001），
这个问题**完全看不见**，只会在别人的电脑上炸。

修法：给 `iphone.ps1` 加 UTF-8 BOM（PS 见到 BOM 就按 UTF-8 读，不再看代码页）。
**改这个文件时不要让编辑器把 BOM「清理」掉**——文件头的注释里也写了这条。

## ⚠️ 删完照片后读取一直超时？（1.2.0 已修）

MTP 规定**一台设备同一时间只能有一个会话**。1.1.0 及以前，插件从来没有调用过
`IPortableDevice::Close()`——六处打开会话的地方，一处都没关，全靠进程退出来收尾。
于是删除之后那个会话还挂在驱动里，下一次读取要等它超时才能拿到新会话；等不到就被
看门狗掐掉，而**掐进程不会执行 finally**，于是又漏一个会话——一次超时就此滚成
「以后每次刷新都超时，只能拔线」。

1.2.0 把六处会话全部改成 `finally` 里 `Close()` 再释放（而且先放子对象、后放设备，
顺序反了等于没关）。删除的超时窗口也从 40s 放宽到 120s：`Delete()` 是一次没法中断、
也没法喂心跳的阻塞调用，删一大批时被掐断正是把设备搞死的元凶。

> 如果你手上这台已经卡死了：**拔掉数据线重插**，会话就没了，之后不会再复发。

## 四、遇到问题先跑「诊断」

因为设备千差万别，如果刷新没反应、看不到照片、或缩略图不出来，
**先跑一下诊断脚本**，把输出发我，我据此修：

1. 插上并解锁手机（iPhone 点过“信任”、安卓切到“传输文件/MTP”）。
2. 打开 **PowerShell**，粘贴运行：
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "F:\我的编程项目\210_Apple照片同步\plugin\scripts\iphone.ps1" -Action diagnose
   ```
3. 把它打印的那一整行 JSON 复制给我。

也可以先列出连了哪些设备：
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "F:\我的编程项目\210_Apple照片同步\plugin\scripts\iphone.ps1" -Action devices
```

或单独测“列出前 20 张”（`-Device` 后填上一步里的设备名，多设备时用得上）：
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "F:\我的编程项目\210_Apple照片同步\plugin\scripts\iphone.ps1" -Action list -Max 20
```

## 五、已知限制 / 待办

- iPhone iCloud「优化存储」的照片无法导出（见上）。
- 安卓会把相机、截图、微信/WhatsApp 等**所有**图片都列出来（不只相机胶卷），
  数量可能比预期多；用顶部筛选和排序来定位。
- 若安卓手机同时有**内部存储 + SD 卡**，且两个存储里存在**完全相同的子路径 +
  同名文件**，二者的内部 id 会撞车（极少见）；实际的复制/删除仍按对象精确定位，
  不受影响，个别情况下可能共用一张缩略图。
- 缩略图/HEIC 预览依赖 Windows 的解码；若系统没装 HEIF 扩展，HEIC 缩略图
  可能出不来（照片仍可选中、导入、备份）。可在 Microsoft Store 搜索安装免费的
  “HEIF 图像扩展”。安卓多为 JPEG，一般不受影响。
- 删除/传输依赖设备的 MTP 实现；个别机型/系统可能限制删除，失败会明确提示，
  可重试或在手机上手动删。
